# Mobile: before and after

Production build against https://api.careermarket.app, captured 10 Nov 2026 on a phone (touch emulation, 2x) at 375 px in both themes and at 414 px in dark. Below `md` (768 px) the desktop cards become mini versions: a sideways row of tiles, a row of short lists, filter chips on one scrolling line, and compact table rows, so the table starts on the first screen. Tablet and desktop are unchanged (pixel-compared at 768, 1024 and 1440 px).
